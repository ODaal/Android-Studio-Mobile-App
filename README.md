# 📱 Service Novigrad – Software Engineering Project

This repository contains our group project for **SEG 2505 – Introduction to Software Engineering** at the University of Ottawa. The goal was to design and implement a mobile application prototype that simulates the services of a fictitious province, **Novigrad**.  

The project allowed us to apply software engineering fundamentals, including **UML modeling, iterative development, teamwork, and Android app development**.

---

## 🚀 Project Overview
The **Service Novigrad app** was designed to simplify public service access for users. It provides:  
- 🔑 **Client account creation** – secure login/registration.  
- 🏢 **Branch search** – find branches by address, service type, or hours.  
- ⭐ **Ratings and reviews** – view evaluations from other users.  
- 📝 **Service requests** – submit requests for driver’s licenses, health cards, or photo IDs.  
- 📬 **Notifications** – receive real-time updates on request status.  
- 📊 **Experience feedback** – rate services after completion.
